# Laboratório de Algoritmos

Repositório criado para registrar as atividades e exercícios
desenvolvidos durante a disciplina de Laboratório de Algoritmos,
realizada no primeiro semestre de Sistemas de Informação.

## Sobre

Os exercícios foram desenvolvidos em Python ao longo do semestre,
com foco no desenvolvimento da lógica de programação e nos
fundamentos da linguagem.

O repositório está organizado por semana para acompanhar a evolução
dos conteúdos e atividades trabalhados durante a disciplina.
